Guide : obtenir l'identifiant d'application Microsoft (une seule fois, ≈ 15 min)
  1. Ouvrez entra.microsoft.com et connectez-vous avec votre adresse Outlook. S'il vous demande de créer un annuaire (« tenant »), créez un compte Azure gratuit.
  2. Applications → Inscriptions d'applications → Nouvelle inscription. Nom : SharedFleet. Types de comptes : Comptes Microsoft personnels uniquement (ou « tout annuaire et comptes personnels »). Pas d'URI de redirection.
  3. Dans l'application créée, onglet Authentification → « Autoriser les flux de clients publics » : Oui → Enregistrer.
  4. Onglet Vue d'ensemble : copiez l'ID d'application (client) et collez-le ci-dessus, puis Enregistrer.
  5. Cliquez sur Se connecter avec Microsoft, saisissez le code affiché sur la page Microsoft et acceptez l'autorisation « Envoyer des e-mails ».
